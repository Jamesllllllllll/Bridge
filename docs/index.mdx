Bridge is a desktop application for finding and downloading rhythm-game charts from Chorus Encore.

## Documentation pilot

This initial deployment tests private access, Git-backed editing, rendering, navigation, and search. User guides, architecture, release, and contributor documentation will be added after the site structure is approved.

## Source of truth

The documentation files live with the Bridge source code. Update them through the same branch and review workflow as code changes so the repository and the published site stay synchronized.
