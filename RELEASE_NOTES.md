Bridge with automatic downloads from chart links.

Download **Bridge-RockList-Setup-3.4.6.exe** below for Windows 10/11 x64. Close Bridge before installing; you do not need to uninstall your existing copy. This build keeps Bridge's settings and library locations.

- Open an exact-chart link from a website to launch Bridge and automatically queue that chart's download.
- Downloads use your existing library folder, chart-folder or `.sng` format, and video preferences.
- Links work with Bridge closed or already running. Multiple links are queued, and repeat links do not create duplicate active downloads.
- If no library folder is configured, Bridge opens Settings and starts the pending downloads once you choose one.
- Normal Bridge searching, downloading, cancellation, and retry remain available.

This is an independent community build based on the latest upstream Bridge source, with additional deep-link support. Future updates come from this fork. RockList's website buttons are not available yet; the app is ready for that integration.

The Windows installer is unsigned. Windows may show an unfamiliar-app warning.
